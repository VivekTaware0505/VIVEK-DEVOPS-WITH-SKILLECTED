# ==========================================
# LINUX LVM COMMANDS
# ==========================================

# Show disks and partitions
lsblk

# Show partition information
sudo fdisk -l

# Show physical volumes
sudo pvs

# Detailed physical volume information
sudo pvdisplay

# Show volume groups
sudo vgs

# Detailed volume group information
sudo vgdisplay

# Show logical volumes
sudo lvs

# Detailed logical volume information
sudo lvdisplay


# ==========================================
# CREATE LVM
# ==========================================

# Create Physical Volume
sudo pvcreate /dev/sdb

# Create Volume Group
sudo vgcreate vgdata /dev/sdb

# Create 20GB Logical Volume
sudo lvcreate -L 20G -n lvdata vgdata

# Create Logical Volume using all free space
sudo lvcreate -l 100%FREE -n lvdata vgdata


# ==========================================
# FILESYSTEM
# ==========================================

# Create ext4 filesystem
sudo mkfs.ext4 /dev/vgdata/lvdata

# Create mount directory
sudo mkdir /data

# Mount Logical Volume
sudo mount /dev/vgdata/lvdata /data

# Show mounted filesystems
df -h

# Show filesystem type
lsblk -f


# ==========================================
# EXTEND LVM
# ==========================================

# Extend LV by 5GB
sudo lvextend -L +5G /dev/vgdata/lvdata

# Extend LV and filesystem
sudo lvextend -r -L +5G /dev/vgdata/lvdata

# Resize ext4 filesystem
sudo resize2fs /dev/vgdata/lvdata


# ==========================================
# ADD STORAGE
# ==========================================

# Create PV from another disk
sudo pvcreate /dev/sdc

# Add PV to existing VG
sudo vgextend vgdata /dev/sdc


# ==========================================
# LVM INFORMATION
# ==========================================

sudo pvs
sudo vgs
sudo lvs
sudo pvdisplay
sudo vgdisplay
sudo lvdisplay
lsblk
df -h














Interview Questions
1. What is LVM?
Logical Volume Management is a Linux storage management system that provides flexible management of storage volumes.
2. What are the three main components of LVM?
PV → VG → LV
3. What is a PV?
Physical Volume — a disk or partition initialized for LVM.
4. What is a VG?
Volume Group — a pool of storage made from one or more PVs.
5. What is an LV?
Logical Volume — a virtual storage volume allocated from a VG.
6. How do you check LVM physical volumes?
sudo pvs
7. How do you check volume groups?
sudo vgs
8. How do you check logical volumes?
sudo lvs
9. What is one major advantage of LVM?
Flexible storage allocation and easier expansion of logical volumes.
10. What is the biggest danger when reducing an LV?
Incorrectly reducing the filesystem/LV can cause data loss.
