A DevOps engineer spends a large part of the day working with files and directories.



mkdir – Create Directories

Create a directory:

Create multiple directories:

rmdir – Remove Empty Directories
rmdir Project

Works only if the directory is empty.

3️⃣ find – Search Files & Directories

Search by name:

find . -name notes.txt

Search from root:

find / -name "*.conf"

Search only directories:

find . -type d

Search only files:

find . -type f

Find files larger than 100 MB:

find / -size +100M
4️⃣ locate – Fast File Search
locate passwd

Update the database:

sudo updatedb

locate is faster than find because it searches an indexed database instead of scanning the disk.

5️⃣ tree – Display Directory Structure

Install:

sudo apt install tree

Run:

tree

Example:

Project/
├── README.md
├── notes.txt
└── images
    └── logo.png
6️⃣ file – Identify File Type
file notes.txt

Example Output:

notes.txt: ASCII text
7️⃣ stat – Detailed File Information
stat notes.txt

Shows:

File size
Owner
Permissions
Last modified time
Last accessed time
Inode number
8️⃣ du – Disk Usage

Current directory:

du

Human-readable:

du -h

Total size:

du -sh .
9️⃣ df – Disk Space
df -h

Shows:

Total disk size
Used space
Available space
Mounted file systems
🔟 Hidden Files

Hidden files begin with a dot (.).

Example:

.bashrc
.profile
.gitignore

Display hidden files:

ls -la
1️⃣1️⃣ Wildcards

ls *.txt

# My Notes

- `find` searches the live file system.
- `locate` searches an indexed database.
- `tree` shows directory hierarchy.
- `stat` provides detailed file metadata.
- `du` shows directory/file usage.
- `df` shows available disk space.
- Hidden files begin with a `.`.
- Wildcards help match multiple files.
