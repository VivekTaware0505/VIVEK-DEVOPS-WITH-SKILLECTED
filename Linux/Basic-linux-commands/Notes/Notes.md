What are Linux Commands?

Linux commands are instructions entered in the terminal to perform tasks like:

Navigating directories
Creating files
Managing folders
Viewing file contents
Copying and moving files
Deleting files
Displaying system information

Most Linux administration is done through these commands.



Common Command Summary
| Command   | Purpose                  |
| --------- | ------------------------ |
| `pwd`     | Show current directory   |
| `ls`      | List files               |
| `cd`      | Change directory         |
| `clear`   | Clear terminal           |
| `history` | Show command history     |
| `echo`    | Print text               |
| `touch`   | Create file              |
| `mkdir`   | Create directory         |
| `rmdir`   | Remove empty directory   |
| `rm`      | Delete files/directories |
| `cp`      | Copy files               |
| `mv`      | Move or rename files     |
| `cat`     | Display file contents    |
| `head`    | Show beginning of file   |
| `tail`    | Show end of file         |
| `less`    | View large files         |

# My Notes

- pwd → Shows current directory.
- ls → Lists files and folders.
- cd → Changes directory.
- touch → Creates a file.
- mkdir → Creates a folder.
- rm -rf → Deletes permanently (use carefully).
- cp → Copies files.
- mv → Moves or renames files.
- cat → Displays file contents.
- tail -f → Monitors log files in real time.
