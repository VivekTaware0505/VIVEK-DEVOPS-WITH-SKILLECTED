chmod g+r file                    -> Give group read permission
chmod o-x file                    -> Remove execute from others

# My Notes

- Linux has three permission classes: Owner, Group, Others.
- r = Read (4)
- w = Write (2)
- x = Execute (1)
- chmod changes permissions.
- chown changes ownership.
- chgrp changes group ownership.
- 755 is commonly used for executable scripts.
- 644 is commonly used for text files.
- 600 is commonly used for SSH private keys.
