# Display all environment variables
env

# Display all environment variables
printenv

# Display specific variable
printenv HOME

# Print variable
echo $HOME

# Important variables
echo $USER
echo $HOME
echo $SHELL
echo $PATH
echo $PWD
echo $OLDPWD
echo $HOSTNAME
echo $LANG
echo $TERM

# Find command location
which ls

# Check command type
type ls

# Create shell variable
NAME="Vivek"

# Read variable
echo $NAME

# Export variable
export NAME

# Create environment variable
export APP_ENV="development"

# Check environment variable
printenv APP_ENV

# Change variable
export APP_ENV="production"

# Remove variable
unset APP_ENV

# View PATH
echo $PATH

# Add directory to PATH temporarily
export PATH="$PATH:$HOME/scripts"

# Reload Bash configuration
source ~/.bashrc

# Edit Bash configuration
nano ~/.bashrc

# Edit profile
nano ~/.profile

# Run command with temporary environment variable
APP_ENV=testing ./app.sh

Interview Questions
1. What is an environment variable?
A named value available to processes in their environment.
2. What is $PATH?
A list of directories that the shell searches for executable commands.
3. What does export do?
It places a shell variable into the environment inherited by child processes.
4. env vs printenv?
Both can display environment variables; printenv is specifically designed to print environment variables.
5. What is .bashrc?
A Bash startup configuration file commonly used for interactive shell settings.
6. What does source ~/.bashrc do?
It executes/reloads the .bashrc file in the current shell.
7. How do you add a directory to PATH?
export PATH="$PATH:/path/to/directory"
8. Why are environment variables useful in DevOps?
They allow applications and deployment processes to receive environment-specific configuration without hard-coding it into source code.
9. Where should passwords/API keys be stored?
Use an appropriate secret-management system or secure secret mechanism—not plain text committed to Git.
10. Give a Docker environment-variable example.
docker run -e APP_ENV=production myapp
