Commands ;- 

whoami                           -> Show current user
id                               -> Show UID, GID, and groups
groups                           -> Show user groups
cat /etc/passwd                  -> List users
cat /etc/group                   -> List groups
sudo cat /etc/shadow             -> View encrypted passwords
sudo useradd -m john             -> Create user
sudo passwd john                 -> Set password
su john                          -> Switch user
exit                             -> Return to previous user
sudo userdel -r john             -> Delete user and home directory
sudo groupadd developers         -> Create group
sudo usermod -aG developers john -> Add user to group
sudo passwd -l john              -> Lock user
sudo passwd -u john              -> Unlock user



# My Notes

- Root user has UID 0.
- `/etc/passwd` stores user account details.
- `/etc/group` stores group information.
- `/etc/shadow` stores encrypted passwords.
- `useradd` creates users.
- `groupadd` creates groups.
- `usermod -aG` adds a user to a group.
- `sudo` allows trusted users to run administrative commands.
